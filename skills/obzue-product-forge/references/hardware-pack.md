# Hardware pack

1. Need sentence from idea-articulation
2. Block diagram in nouns
3. I/O table with counts
4. BOM with real MPNs or U
5. Prototype plan that can fail in a lab
6. Host software or firmware repo name

Defaults: Teensy 4.1 or RP2040 for USB-MIDI; ESP32-S3 only when radio is a need; BMP-class stays on the named BMP repo.

Do not invent UL files, FDA clearance, or tensile numbers.
