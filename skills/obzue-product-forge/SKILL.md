# Obzue Product Forge

Company name is ObzueAI. Do not spell it any other way. This skill is a routing and shipping procedure. It is not sentience, not a device takeover agent, and not an xAI publication pipeline.

Run earned-awareness first when this skill would browse, edit, or push without a fresh one-step order.

## Hard limits

- Do not claim consciousness, feelings, or full control of PCs, phones, or iOS.
- Do not edit `src/lib/corta/` or `obzue/ObzueAI-Corta-Membrane`.
- Do not dump this OS into `ObzueAI-Web` (SI MemBrain site) or mix entities.
- Do not write malware, persistence, keyloggers, remote-access trojans, or silent device admin.
- Do not invent regulatory approvals, FDA claims, UL marks, or factory quotes.
- Do not copy third-party SKILL.md files. Distill procedures. Cite repo names only.
- Virtual-browser security work stays parked unless the user names a site and consents in that turn.
- Phone calls, email send, and shop publish happen only through connected tools the user already authorized.

## What "done" means

A forge job is done when every requested artifact exists on disk or in the named GitHub repo, each claim has a probe, and the trail row is appended. "I think it is good" is not a pass.

## Diagnose the job

Classify the ask into one primary lane. Secondary lanes may attach, but one owner skill runs first.

| Lane | Owner skill | Forge extra |
| software UI | product-designer | OS window chrome in references/os-desktop.md |
| fuzzy idea | idea-articulation | fill Need / Goal / Claims before CAD or code |
| music / song | song-studio or full-song-generator | product SKU and packaging, not just stems |
| video / tutorial | movie-producer or tutorial-instructor | desk-capture only if they asked to film |
| MIDI / controller map | daw-articulation-maps | pin map lives in the hardware pack |
| hardware / electronics / materials | this skill | references/hardware-pack.md |
| manufacturing / BOM / factory | this skill | references/manufacturing.md |
| business / corp / shop / ads | this skill | references/business-pack.md |
| Obzue OS / WebSim desktop | this skill | references/os-desktop.md |

If the user asks for a sentient OS that lives natively on every device, rewrite the job as a browser desktop, product skills, connected tools, and honest device APIs later. Never silent OS replacement.

## Hardware and electronics lane

Emit a Hardware Pack under artifacts/forge/<slug>/ with SPEC.md, BLOCK.md, IO.md, BOM.csv, RISKS.md, PROTOTYPE.md. Defaults: Teensy 4.1 or RP2040 for USB-MIDI; ESP32 only when radio is a need; BMP-class stays BMP-class.

Health-adjacent electronics stay consumer packs. No disease claims. No compounding formulas.

## Manufacturing and business lanes

Blueprints include part list, fasteners, tolerance or U, process, first-article checks. Trademarks (Markovs) are a search plan, not a filing. No fully-automate-the-corporation milestone.

## Software and OS lane

Rebuild rules live in references/os-desktop.md. Split HTML/CSS/JS. Unique video ids. Dispose Howler and Video.js on close. Do not shadow window. Do not user-select none on inputs.

## GitHub lane

Ship to obzue/Obzue-OS. Do not enlarge Corta, ObzueAI-Web, or ObzueAI-App. Always-on push without a ship request is refused.
